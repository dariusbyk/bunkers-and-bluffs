## 1. Назначение

Документ описывает общую структуру для страницы лобби.

## 2. Состав интерфейса

### 2.1. Основные блоки страницы

| Блок                            | Местонахождение | Ограничения | Назначение                                                    |
| ------------------------------- | --------------- | ----------- | ------------------------------------------------------------- |
| Блок «Информация о лобби»       | Страница лобби  | -           | Содержит основную информацию о комнате                        |
| Блок «Характеристики мира»      | Страница лобби  | -           | Содержит характеристики катастрофы и бункера                  |
| Блок «Характеристики персонажа» | Страница лобби  | -           | Содержит характеристики персонажа игрока                      |
| Блок «Панель управления»        | Страница лобби  | -           | Содержит панель управления участника лобби                    |
| Блок «Таблица игроков»          | Страница лобби  | -           | Содержит список всех игроков и их характеристики для открытия |
| Блок «Гейм-мастер»              | Страница лобби  | -           | Содержит отдельно ГМ лобби                                    |

Порядок блоков на странице должен быть таким же, как и в таблице.

## 3. Скриншоты и макеты

На данном этапе разработке дизайн не создан.

## 4. Обработки ошибок

| Ошибка                           | Обработка                                                                                                       | Уведомление                                            |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Обновление страницы              | Всё состояние участника сохраняется, он остаётся в лобби                                                        | -                                                      |
| Закрытие вкладки                 | Всё состояние участника сохраняется, он остаётся в лобби<br><br>При отключении ГМ таймер партии останавливается | Пометка у игрока о потере связи в таблице игроков      |
| Ошибка подключения               | Всё состояние участника сохраняется, он остаётся в лобби<br><br>При отключении ГМ таймер партии останавливается | Уведомление с соответствующей ошибкой для пользователя |
