## 1. Назначение

Данный документ описывает игровую механику характеристик бункера.

## 2. Основное описание

Бункер — это основной способ спасения персонажей в мире игры и следовательно способ выигрыша в партии. В большинстве случаев это некое герметичное подземное сооружение, способное пережить грядущую катастрофу.

В бункере физически не может находиться больше персонажей, чем предусмотрено его вместимостью. 
### 2.1. Характеристики бункера

| Характеристика           | Способ получения игрой                                                                    | Пример                                                                                        |
| ------------------------ | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Количество мест          | `Количество мест = floor(Количество игроков / 2)`                                         | В комнате 9 игроков. Значит в бункере 4 места                                                 |
| Описание бункера, 3 шт.  | Берётся случайным образом из заготовленных в БД                                           | **•** В помещении сухо<br>**•** Находится в пустыне<br>**•** Имеется небольшая щель в потолке |
| Инвентарь бункера, 3 шт. | Берётся случайным образом из заготовленных в БД                                           | **•** Мастерская с инструментами<br>**•** Радио<br>**•** Склад медикаментов                   |
| Срок обеспечения пищей   | `Срок обеспечения пищей = ceil(время пребывания × случайный коэффициент от 0,75 до 1,25)` | 38 месяцев для `количество мест`                                                              |
