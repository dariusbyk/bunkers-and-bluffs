## 1. Назначение

Документ описывает экраны и элементы, через которые пользователь создаёт лобби или подключается к нему.

## 2. Состав интерфейса

Состав интерфейса включает в себя следующие элементы:

| Элемент                       | Местонахождение        | Ограничения                                                                      | Назначение                                    | Поведение                                                                                                                                                                                                                              |
| ----------------------------- | ---------------------- | -------------------------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Кнопка «Создать лобби»        | Главная страница сайта | -                                                                                | Инициирует создание комнаты                   | **●** Неавторизованный пользователь:<br><br>Открывается окно «Вход в аккаунт».<br><br>**●** Авторизованный пользователь:<br><br>Перекидывает на страницу созданного лобби.<br>                                                         |
| Поле «Код лобби»              | Главная страница сайта | 1. Поле не может быть пустым.<br><br>2. 6 символов: латинские буквы и/или цифры. | Позволяет указать код комнаты для подключения | При нарушении ограничений появляется соответствующая подсказка                                                                                                                                                                         |
| Кнопка «Подключиться к лобби» | Главная страница сайта | -                                                                                | Инициирует подключение по указанному коду     | **●** Неавторизованный пользователь:<br><br>Открывается окно «Вход в аккаунт».<br><br>**●** Авторизованный пользователь:<br><br>Если данные введены корректно, пользователя перенаправляет на страницу лобби, к которому привязан код. |

## 3. Скриншоты и макеты

На данном этапе разработке дизайн не создан.

## 4. Обработки ошибок

| Ошибка                                                          | Обработка                                          | Уведомление                           |
| --------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------- |
| Неверный код лобби                                              | Пользователь остаётся на странице ввода кода лобби | Уведомление с соответствующей ошибкой |
| Недоступное лобби из-за неподходящего этапа или переполненности | Пользователь остаётся на странице ввода кода лобби | Уведомление с соответствующей ошибкой |
| Ошибка подключения                                              | Пользователь остаётся на странице ввода кода лобби | Уведомление с соответствующей ошибкой |
| Пользователь уже состоит в лобби                                | Переадресация на актуальное лобби пользователя     | Уведомление с соответствующей ошибкой |
