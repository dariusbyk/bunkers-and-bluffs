## 1. Назначение

Документ описывает игровую механику «Вылазки».

## 2. Основное описание

Вылазки — это игровая механика, позволяющая игрокам совершать условные "вылазки" в поисках ресурсов.

Основная цель данной механики — дать возможность игрокам, которым не повезло с генерацией характеристик персонажа, иной путь к спасению своего персонажа. Они могут найти предметы, которые могут перевернуть ход партии, если они ими правильно воспользуются.

Пре переходе на следующий раунд, начиная со второго и до предфинального раунда включительно, у игроков появляется выбор — пойти на вылазку или нет.

Персонажи, ушедшие на вылазку, не имеют права в течение текущего раунда участвовать в открытии характеристик, совершении действий и голосовании. При этом, у них случайным образом открывается одна характеристика персонажа.

На вылазке они могут найти случайный предмет, ничего не найти или получить урон по ОЗ. Результат определяется броском кубика.

Игроки возвращаются в игру в начале следующего раунда.

При снижении ОЗ до нуля, используется механика без сознания из боевой системы. Чтобы не создавать лишних трудностей, игрок смог добраться до лагеря и уже в нём потерял сознание. Подробнее в следующем документе:
[[06 MVP — Игровые механики — Боевая система|MVP — Игровые механики — Боевая система]]

## 2.1. Определение результата вылазки

Результата вылазки определяется броском кубика по следующей формуле и таблице:

> Результат вылазки = d20 + Наблюдательность

|                    Итог | Исход                                                             |
| ----------------------: | ----------------------------------------------------------------- |
|          **8 и меньше** | Персонаж получает -1 ОЗ и возвращается без предмета               |
|                **9–13** | Возвращается без находок и без урона                              |
|         **14 и больше** | Находит один случайный предмет                                    |
| **Критическая неудача** | Персонаж получает -2 ОЗ и возвращается без предмета               |
|   **Критическая удача** | Персонаж может получить любой предмет на выбор и на усмотрение ГМ |
Критическая удача и неудача считаются без модификатора.
