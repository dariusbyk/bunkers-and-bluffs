## 1. Назначение

Документ описывает экраны и элементы, через которые пользователь регистрирует или входит в аккаунт.

## 2. Состав интерфейса

### 2.1. Модальные окна

Состав интерфейса включает в себя следующие модальные окна:

| Модальное окно              | Ограничения                                                             | Путь вызова                                                                                                                                                                           | Поведение                                                                                            |
| --------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Окно «Регистрация аккаунта» | Пользователь, который уже зашёл в аккаунт, не может попасть в это окно. | **●** Пользователь нажимает кнопку «Регистрация аккаунта» в окне «Вход в аккаунт»                                                                                                     | Все пользователи, которые уже зашли в аккаунт, должны быть переадресованы на главную страницу сайта. |
| Окно «Вход в аккаунт»       | Пользователь, который уже зашёл в аккаунт, не может попасть в это окно. | **●** Неавторизованный пользователь нажимает кнопку «Вход в аккаунт» в хедере «Шапка сайта».<br><br>**●** Пользователь нажимает кнопку «Вход в аккаунт» в окне «Регистрация аккаунта» | Все пользователи, которые уже зашли в аккаунт, должны быть переадресованы на главную страницу сайта. |

## 4. Обработки ошибок

| Ошибка                                                            | Обработка                                                            | Уведомление                           |
| ----------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------- |
| Ошибка подключения                                                | Пользователь остаётся в окне «Вход в аккаунт»\«Регистрация аккаунта» | Уведомление с соответствующей ошибкой |
| При входе система не нашла аккаунт с ведёнными данными            | Пользователь остаётся в окне «Вход в аккаунт»                        | Уведомление с соответствующей ошибкой |
| Ошибка отправки письма с  проверочным кодом                       | Пользователь остаётся в окне «Регистрация аккаунта»                  | Уведомление с соответствующей ошибкой |
| При проверке кода с почты, введённый код не совпал с отправленным | Пользователь остаётся в окне «Регистрация аккаунта»                  | Уведомление с соответствующей ошибкой |
| При регистрации указанная почта совпала с уже зарегистрированной  | Пользователь остаётся в окне «Регистрация аккаунта»                  | Уведомление с соответствующей ошибкой |
| При регистрации указанный ник совпал с уже зарегистрированным     | Пользователь остаётся в окне «Регистрация аккаунта»                  | Уведомление с соответствующей ошибкой |
