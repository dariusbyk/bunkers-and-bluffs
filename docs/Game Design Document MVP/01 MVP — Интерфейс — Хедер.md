## 1. Назначение

Документ описывает основной хедер проекта.

## 2. Состав интерфейса

Основной хедер сайта называется «Шапка сайта».
Он находится сверху любой страницы сайта.

### 2.1. Выпадающие меню

Состав интерфейса включает в себя следующие выпадающие меню:

| Модальное окно              | Ограничения                                          | Путь вызова                                                                                                 | Поведение                                                     |
| --------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Меню «Управление аккаунтом» | Только авторизированные пользователи видят это меню. | Пользователь кликает по картинке «Картинка профиля в хедере» или по надписи «Никнейм пользователя в хедере» | После вызова меню меню «Управление аккаунтом» должно выпасть. |

### 2.2. Элементы 

Состав интерфейса включает в себя следующие элементы:

| Элемент                                           | Местонахождение             | Ограничения                                                      | Назначение                                                       | Поведение                            |
| ------------------------------------------------- | --------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------ |
| Кнопка «Окно входа в аккаунт»                     | Хедер «Шапка сайта»         | Эта кнопка появляется только для неавторизованных пользователей. | Инициирует появление окна «Вход в аккаунт»                       | Появляется окно «Вход в аккаунт»     |
| Картинка «Картинка профиля в хедере»              | Хедер «Шапка сайта»         | Эта картинка видна только для авторизованных пользователей.      | Позволяет инициализировать выпадение меню «Управление аккаунтом» | Выпадает меню «Управление аккаунтом» |
| Надпись «Никнейм пользователя в хедере»           | Хедер «Шапка сайта»         | Эта надпись видна только для авторизованных пользователей.       | Позволяет инициализировать выпадение меню «Управление аккаунтом» | Выпадает меню «Управление аккаунтом» |
| Кнопка «Выйти из аккаунта в управлении аккаунтом» | Меню «Управление аккаунтом» | Эта надпись видна только для авторизованных пользователей.       | Позволяет инициализировать выход из аккаунта                     | Производится выход из аккаунта       |


## 3. Скриншоты и макеты

На данном этапе разработке дизайн не создан.

## 4. Обработки ошибок

| Ошибка             | Обработка                                  | Уведомление                           |
| ------------------ | ------------------------------------------ | ------------------------------------- |
| Ошибка подключения | Пользователь остаётся на текущей странице. | Уведомление с соответствующей ошибкой |
