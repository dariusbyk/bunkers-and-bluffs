## 1. Назначение

Документ описывает стадию «Финал игры».

## 2. Границы этапа

Стадия заканчивается после выбора победителей партии. После этой стадии ничего нет — игра заканчивается.

## 3. Основное описание

Эта стадия завершает всю парти. В ней ГМ выбирает победителей — игроков, чьи персонажи смогли пережить катастрофу.

В этой стадии применять способности нельзя.

### 3.1. Выбор победителя

После конца финального раунда, ГМ в открывшемся окне должен выбрать всех выживших персонажей — победителей игры. При этом, победителей может и не быть.

После выбора все игроки могут ознакомиться с результатами. 

### 3.2. Возможности участников

На этапе финала игры, исключительно ГМ доступны следующие действия:

| Действие                        | Ограничение                                    | Назначение                                                      | Результат                                          |
| ------------------------------- | ---------------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------- |
| Выбор победителя                | -                                              | Позволяет ГМ выбрать победителей партии                         | Высвечивается список победивших игроков            |
