## 1. Назначение

Документ описывает этап «Сбор лобби» на подготовительной стадии игры.

## 2. Границы этапа

Этап заканчивается переходом на следующий этап подготовительной стадии — генерация мира. Когда именно совершится переход — решает ГМ.

## 3. Основное описание

На этом этапе участники подключаются к лобби, знакомятся с друг другом и управляют своим присутствием в комнате. Результат этапа — успешное подключение всех игроков к лобби, распределение ролей и переход к следующему этапу.

Минимальное количество игроков для перехода на следующий этап — 6, максимальное —12

Созданное лобби автоматически удаляется из памяти игры после 24 часов после создания, если оно не дошло до финала.

### 3.1. Код комнаты

Код идентифицирует комнату и используется для подключения других участников. Код состоит из шести символов: латинские буквы и/или цифры.

### 3.2. Роли и права

Начиная с этого этапа, участник лобби имеет одну из двух ролей: гейм-мастер или игрок.

| Роль | Назначение |
| --- | --- |
| Гейм-мастер (ГМ) | Управляет лобби и игровым процессом |
| Игрок | Участвует в партии и управляет своим персонажем после его генерации |

По умолчанию ГМ является создатель комнаты. 

### 3.2. Исходные состояния участников

Пользователь, создавший лобби, автоматически получает роль ГМ и выносится в блок «Гейм-мастер».

Пользователь, подключившийся к созданному кем-то лобби, автоматически получает роль Игрока, статус «Не готов» и выносится в блок «Таблица игроков».

## 4. Возможности участника

На этапе сбора лобби, исключительно игроку доступны следующие действия:

| Действие                | Ограничение | Назначение                                                                                                                                              | Результат                                        |
| ----------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Переключение готовности | -           | Позволяет переключиться между режимами «Не готов» и «Готов». Функция не позволяет запускать основную игру, если ещё остались неподготовленные участники | Переключение между режимами «Не готов» и «Готов» |
| Выход из лобби          |             | Позволяет выйти из лобби по желанию игрока                                                                                                              | Выход из лобби                                   |

На этапе сбора лобби, исключительно ГМ доступны следующие действия:

| Действие              | Ограничение                                                                                        | Назначение                           | Результат                                                                              |
| --------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------- |
| Удаление лобби        | -                                                                                                  | Позволяет удалить лобби              | Удаляет лобби. Все участники лобби переадресуются на главную страницу сайта            |
| Генерация мира        | Для перехода к следующему этапу нужно набрать минимальное количество участников — 6 игроков и 1 ГМ | Позволяет перейти к следующему этапу | Переход к следующему этапу                                                             |
