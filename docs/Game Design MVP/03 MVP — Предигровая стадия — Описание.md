## 1. Назначение

Документ описывает предигровую стадию игры.

## 2. Границы стадии

Стадия заканчивается входом в лобби.

## 3. Основное описание

На предигровой стадии игрок исполняет все требования проекта для доступа к игре, после этого получает возможность подключиться или создать лобби.

### 3.1. Основные возможности

На предигровой стадии пользователю доступны следующие действия:

| Действие                                        | Ограничение                                                                                                                                          | Назначение                                                                       | Результат                                            |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Регистрация нового аккаунта                     | Пользователь должен быть неавторизован                                                                                                               | Позволяет пользователю создать новый аккаунт для игры на проекте                 | Пользователь создаёт для себя новый аккаунт          |
| Авторизация в существующий аккаунт              | Пользователь должен быть неавторизован и у него должен быть зарегистрированный аккаунт                                                               | Позволяет пользователю авторизоваться в существующий аккаунт для игры на проекте | Пользователь авторизовывается в существующий аккаунт |
| Создание нового лобби пользователем             | Для доступа к игре пользователь должен быть авторизован                                                                                              | Позволяет создать новое лобби                                                    | Создание нового лобби                                |
| Подключение к существующему лобби пользователем | 1. Для доступа к игре пользователь должен быть авторизован.<br><br>2. Лобби доступно к подключению только когда оно находится на этапе «Сбор лобби». | Позволяет подключиться к существующему лобби                                     | Подключение к существующему лобби                    |
