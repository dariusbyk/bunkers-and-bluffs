## 1. Назначение

Документ описывает игровую механику «Степень утраты морали».

## 2. Основное описание

Степень утраты морали — это характеристика, которая ограничивает совершение аморальных поступков.

Аморальный поступок — это действие, требующее израсходования степени утраты морали. Аморальность поступка определяется ГМ. В большинстве случаев, это действия, которые влекут смерть или насилие по отношению к другим персонажам.

Основная цель уровня упадка морали — сделать так, чтобы игра не превращалась в бесконечную череду убийств и драк.

Каждая степень утраты морали позволяет совершать определённое количество аморальных поступков. Если лимит закончился, то персонаж не может совершать больше аморальных поступков, пока не повысит степень утраты морали снова.

## 2.1. Уровни упадка морали

Характеристика степень упадка морали подразумевает в себе следующие градации:

| Степень | Название               | Количество аморальных поступков |
| ------- | ---------------------- | ------------------------------- |
| 0       | Нравственность         | 0                               |
| 1       | Нравственное колебание | 1                               |
| 2       | Нравственное падение   | 2                               |
| 3       | Моральное разложение   | 3                               |
| 4       | Бесчеловечность        | Без лимита                      |

## 2.2. Повышение степени утраты морали

Изначальная степен утраты морали задаётся карточными характеристиками персонажа. Но её так же можно повысить в ходе игры.

Существует два типа повышения степени утраты морали: 

**•** Временное повышение — повышает степень на определённое количество раундов, пока игрок не решит её потратить. На сколько раундов — решает ГМ.

**•** Постоянное повышение — повышает степень на всю игру, пока игрок не решит её потратить.

Утрата морали повышается следующими способами:

| Способ                                                                         | Тип повышения                              | Получаемая степень              |
| ------------------------------------------------------------------------------ | ------------------------------------------ | ------------------------------- |
| Употребление алкоголя                                                          | Временное повышение                        | +1 степень или на усмотрение ГМ |
| Употребление дурманящих средств                                                | Временное повышение                        | +1 степень или на усмотрение ГМ |
| Определённый отыгрыш или попадание персонажа в определённые игровые ситуации   | Временное повышение / Постоянное повышение | На усмотрение ГМ                |
| Если персонаж не смог найти себе путь к спасению после закрытия дверей бункера | Постоянное повышение                       | Степень «Моральное разложение»  |
